    How layers work & tips

    1. Select a vocals-only audio file in the library (Split song in Practice can make one). 2. Load an arrangement or add layers, then press Live preview and adjust while it plays. 3. Render the mix, then use Effects for reverb and Edit → Save as to export.

    These are starting settings based on common production techniques, not copies of any artist's sound. Artificial doubles are delayed copies, so check that the mix doesn't sound hollow or phasey. Separately sung takes usually sound more natural: choose them as a layer's Source.

    Fixed pitch intervals: +3 minor third, +4 major third, +7 fifth, −12 octave below. They don't follow your key or chords automatically, so solo a harmony to check it. Mute leaves a layer out; Solo plays only the soloed layers.

    Other sounds (voice only, guitar only, lo-fi, radio…)

    A preset saves only the settings (the slider positions), not any audio, so you can reuse your favourite sound on future recordings in one click. Presets are kept in this browser. To make the audio file, use Apply effects → new copy.

    Clean up

    The cover presets use no noise gate, so quiet guitar notes and natural string decay are kept. Leave hiss reduction off when the recording is already quiet.
